# Olympus entrance artwork

- Asset: `public/olympus-gates.svg`.
- Created with the built-in image generation tool using the supplied Elysian Gates / Commissioner Thundercock image as the edit target.
- The SVG is a transport wrapper around the generated raster image encoded as WebP. It contains no scripts, external resources, or vector recreation of the scene. This lets the GitHub connector's UTF-8 contents API commit the self-contained artwork.
- The WebP is encoded at quality 86; the bundled wrapper is approximately 377 KB.
- The entrance presents the artwork at full width on narrow screens so the statue and gate remain visible. The profile form is separate accessible HTML.
- Account authentication is not implemented; the entrance selects an existing local demo profile.
